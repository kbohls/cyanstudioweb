# Cyan Studio — Website

Online shop for Cyan Studio, Ucluelet BC. Original cyanotype prints and limited edition reproductions handcrafted using sun-printing and hand-collected coastal botanicals.

---

## About

Cyan Studio is run by Krista Bohlen from Ucluelet, BC on the west coast of Vancouver Island, on the traditional territory of the Yuułuʔiłʔatḥ (Ucluelet) First Nation.

Cyanotype is one of the oldest photographic processes — images developed using ultraviolet light from the sun. Each composition is carefully handcrafted using seaweeds and coastal botanicals collected by hand from the shoreline around Ucluelet.

When not making art, Krista studies seaweed for a living — working on kelp and nearshore habitat mapping, monitoring, and restoration.

---

## Managing the shop

Products, availability, photos, and prices are managed through the admin panel at **/admin** — log in with your GitHub account.

To mark something as sold out, open the product and toggle **Available for sale** off. To add a new piece, click **New Product** and fill in the form.
